### 👨‍💻 Sobre Mí

Soy un **Ingeniero de Software** y **Desarrollador Full Stack** egresado de la Universidad Tecnológica de la Huasteca Hidalguense (UTHH). Me apasiona resolver problemas complejos de negocio traduciéndolos en código limpio, eficiente y escalable. 

Mi mayor fortaleza es mi curiosidad técnica: **me encanta aprender nuevas tecnologías constantemente** y adaptarme a los retos del desarrollo moderno. No solo construyo aplicaciones aisladas, sino **ecosistemas completos** que conectan plataformas web, aplicaciones móviles y dispositivos del Internet de las Cosas (IoT) como smartwatches y asistentes de voz. 

Trabajo fuertemente bajo **metodologías ágiles** (Scrum, Kanban) para garantizar entregas continuas y de valor. Ya sea diseñando una base de datos relacional, entrenando un modelo básico de Machine Learning o creando una interfaz de usuario intuitiva, mi enfoque siempre es la calidad y la experiencia del usuario.

### 🚀 Proyectos Destacados

#### 🏢 Ecosistema: Alquiladora Romero
Una suite integral de logística empresarial y gestión de inventarios, diseñada bajo una arquitectura multicanal:
- 💻 **Plataforma Web:** Panel administrativo centralizado para la gestión operativa y de rentas.
- 📱 **Aplicación Móvil:** Herramienta para la gestión en campo, logística y seguimiento de entregas en tiempo real.
- ⌚ **Wear OS:** Extensión para smartwatches que permite consultar el estatus de las operaciones rápidamente desde la muñeca.
- 🎙️ **Skill de Alexa:** Interfaz conversacional por voz para consultar disponibilidad de inventario y agenda de eventos.

#### 🍔 Plaza de Sabor
- Plataforma digital orientada a la industria gastronómica para la gestión, visualización y descubrimiento de ofertas culinarias, con un fuerte enfoque en UI/UX y rendimiento.
